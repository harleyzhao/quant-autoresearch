## 1. 立项理由（摘要）

1. SpeedTree 10 的算法内核仍是 1995 年 Weber-Penn 式参数化 generator，季节是贴图切换，分叉是圆管加靴口，材质靠 999 美元/年的库订阅，桌面单机授权。
2. 2009 年以来的自组织生长模型与 2023–2025 年的神经方法（DeepTree、Latent L-systems、Autoregressive Trees、Tree-D Fusion）以及 2024–2025 年的 strand 体积模型，已在真实感和可控性上超越它，但没有产品化。
3. UE 5.7 的 Procedural Vegetation Editor 与 Nanite Foliage 正在吞掉「游戏 + UE」这块，但没有解决跨引擎、电影近景、时间轴、程序化材质与 Web 协作。PlantFactory 已停止开发，高端离线市场出现空缺。
4. WebGPU 已在全部主流浏览器默认开启，three.js WebGPURenderer 生产可用，Rust→WASM 链路在本环境验证通过。

## 2. 目标与非目标

**P0（技术验证，3 个月）目标**
- 自组织生长内核：芽竞争光与空间、Borchert–Honda 资源分配、顶端优势、向光/向重性、枝条脱落、管道模型次生生长。确定性（同 seed 同结果）。
- 物候模型：积温驱动萌芽，日历驱动衰老与落叶，叶片按曝光与随机相位逐片变色与脱落；常绿针叶另行处理。
- 骨架 → 枝干网格 + 叶片实例，three.js WebGPU 查看器（WebGL2 回退），参数面板，URL 分享，glTF 导出，无头截图冒烟测试。
- 3 个物种（栎、桦、松）作为回归基线；测试覆盖确定性、包络约束、管道模型比值、物候序列、网格有效性。

**2026-09-06 调整（发起人决定）**：核心是把外观做正确，并把物种数量做到 SpeedTree 资产库量级（数百种）。因此程序化叶片与树皮贴图提前进入 P0，P0 目标物种数为 12；环境/AI 反推/USD 后移。路线见 `04-外观与物种规模路线.md`。

**P0 明确不做**：strand 体积模型、风、LOD/impostor、USD/FBX、云端、AI 反推。

**P0 出口标准**
- `pnpm test`、`pnpm typecheck`、`pnpm build`、`pnpm smoke` 全绿并进 CI。
- 三个物种在 25 年树龄下于 Worker 内 ≤ 3 s 生成（当前 TS 内核），并有明确的 WASM 移植性能门槛（ADR-002）。
- 12 个物种，每种有程序化叶片贴图（反照率/alpha/法线）与程序化树皮，四季可用。
- 内部盲评：每物种 ≥ 3/5 美术认为「像该物种」。

## 5. 工作方式

- 分支：`main` 受保护；功能分支 + PR；CI 必须绿。当前立项工作在 `claude/procedural-plant-generation-aozx32`。
- 每个非显然的技术决定写一条 ADR（`arbor/docs/adr/`）。
- 每两周一次里程碑评审：看数据（测试、性能表、盲评分），不看 demo 感觉。
- 真实感度量（方案 §13）从 P0 起就跑：管道模型比值、包络填充率、分枝角分布；每物种发布前过门槛。

**已知问题（P0 待办，按优先级）**
1. 性能：25 年树从零生成约 0.5–1.2 s（单线程 TS，优化后）。年龄与季节滑条为增量（PlantSession：向前只算新增年份，换日期只重建叶片，30–150 ms）。剩余热点是赤松成千末梢芽的锥形感知查询。
2. 赤松针叶密度仍低于真实（针叶簇为无贴图几何）；材质与 alpha 卡片在 P1。
3. 叶片仍是无贴图单色卡片；树皮为单色。
4. 尚无风、LOD、impostor、USD。
