# 外观正确性与物种规模路线

> 2026-09-06 发起人决定：核心是把外观做正确，物种数量对标 SpeedTree 资产库（官方描述为「数百个树种」，每种带 4K PBR、季节与风）。本文件替代立项书 §2 中「P0 不做材质」的约定：材质与器官外观提前到 P0，环境/AI 反推后移。

## 1. 目标数字

| 阶段 | 物种数 | 每物种交付 | 验收 |
|---|---|---|---|
| P0 末（+3 月） | 12 | 程序化叶片贴图（反照率/alpha/法线/透射）、程序化树皮、四季、参考照片对照页 | 盲评：≥ 3/5 美术认为「像该物种」 |
| P1 末（+9 月） | 60 | 上述 + 叶簇卡片 LOD、花/果（有的物种）、风 | 每物种 ≤ 4 小时 TD 工时 |
| P2 末（+15 月） | 200+ | 上述 + 4K 烘焙、材质变体（幼/老/病/湿） | 覆盖温带/北方/地中海/热带/干旱 5 个生物群系 |

数百物种的唯一可行方式是**程序化生成器官与材质 + 继承式物种定义**，而不是逐种手工建模与扫描。扫描只用于校准与少数英雄资产。

## 2. 物种定义的三层继承

```
Archetype（生长型原型，约 12 个）
  excurrent-conifer / decurrent-broadleaf / columnar / weeping / spreading /
  multi-stem-shrub / palm / tree-fern / bamboo / succulent / vine / cactus
    └─ Genus（属，约 60 个）：叶形族 + 树皮族 + 物候类别 + 分枝习性
         └─ Species / Cultivar（种/品种，200+）：≤ 10 个覆盖参数 + 参考照片 + 颜色
```

- 新物种 = 选原型 + 选属 + 填 10 个参数。目标 1 小时/种（P2 工具成熟后）。
- 所有层的参数都有植物学含义与合法范围；越界在校验脚本里报错。
- 每个物种目录：`species/<id>.json`、`refs/`（≥ 6 张参考照片链接：全株四季、树皮、叶正反面）、`notes.md`。

## 3. 程序化器官

### 3.1 叶片（本周开始）

叶形族（family）与参数：

| 族 | 参数 | 例 |
|---|---|---|
| simple（单叶） | 长宽比、最宽处位置、基部/顶部形状、锯齿（幅度/频率）、叶柄长 | 桦、榆、山毛榉、樱 |
| lobed（裂叶，羽状裂） | 裂片数、裂深、裂片圆/尖 | 栎 |
| palmate（掌状） | 裂片数、裂深、中心角 | 槭、悬铃木 |
| pinnate（羽状复叶） | 小叶数、小叶形、叶轴长 | 白蜡、核桃、刺槐 |
| bipinnate | 二级小叶 | 合欢、蓝花楹 |
| needle | 束生数、长度、截面 | 松、云杉、冷杉 |
| scale | 鳞片排列 | 柏、崖柏 |
| frond | 羽片数、弯曲 | 棕榈、蕨 |

流水线：参数 → 轮廓多边形 → 叶脉（主脉 + 二级脉，掌状为放射）→ 栅格化为贴图集：
反照率（叶脉/叶肉色差、叶缘、斑点）、alpha、法线（叶脉凸起 + 叶面起伏）、透射、粗糙度。
季节由内核每叶的色素通道驱动，贴图存「结构」，颜色在着色器里混。

### 3.2 树皮

树皮族：smooth（山毛榉）、lenticel（桦、樱）、furrowed（栎、白蜡）、plated（松、悬铃木老树）、fibrous（雪松、红杉）、exfoliating（悬铃木、桉）、ridged（榆）。
参数随直径与枝龄变化（细枝光滑、主干开裂），在材质里读几何侧的直径与年龄。

### 3.3 花与果（P1）

按属定义：花序类型、花期窗口、颜色；果实形状与挂果期。

## 4. 渲染与 LOD 对外观的要求

- 叶片：alpha 裁剪卡片 + 双面 + 透射；近景用真实叶片网格（弯曲、卷边）。
- 叶簇卡片：远端细枝加叶烘焙为簇卡片（SpeedTree 的 frond 做法），密度与性能同时解决。
- 树皮：位移或视差，分叉处纹理连续。
- 每物种一张「对照页」：Arbor 渲染 × 参考照片 × 四季，进 CI 工件，是盲评材料。

## 5. 批量校准与验收

- `pnpm metrics`：结构统计（已做）。
- `pnpm contact-sheet`：所有物种 × 四季 × 两个树龄的缩略图拼板（待做）。
- 盲评表：每物种 5 人打分，未过门槛不进库。
- 参考数据：公开物种图鉴与 LiDAR 数据集用于校准分枝角、冠形、树皮。

## 6. 对现有计划的调整
